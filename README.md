# Набор SVG символов и отдельных спрайтов клавиатуры для TurboWarp / Scratch 3.0

Полный комплект всех символов английской раскладки клавиатуры (**US QWERTY, ASCII 32–126**) в виде **отдельных спрайтов для TurboWarp** (по одному спрайту на каждый символ/клавишу), а также чистых векторных **SVG-файлов**.

---

## 🎮 Готовые проекты TurboWarp (.sb3)

Просто откройте [turbowarp.org](https://turbowarp.org) (или десктопный TurboWarp) и выберите **Файл → Загрузить с компьютера**:

1. **`turbowarp_all_95_symbols_sprites.sb3`**
   - **95 отдельных спрайтов на сцене!**
   - Ровно по одному спрайту на каждый печатный символ с клавиатуры: заглавные `A-Z`, строчные `a-z`, цифры `0-9`, знаки препинания и спецсимволы.
   - Расставлены по сетке на экране. Каждый спрайт можно перетаскивать, кликать и менять костюмы.

## 💡 Что внутри каждого отдельного спрайта

Каждый спрайт в папке `04_individual_sprites/` содержит 4 готовых костюма:
1. **`key_light`** — светлая объемная клавиша клавиатуры.
2. **`key_pressed`** — нажатая клавиша со сдвигом вниз (для эффекта клика).
3. **`key_dark`** — темная стильная клавиша.
4. **`glyph`** — чистый плоский векторный символ без рамки кнопки.

Векторные контуры чистые, без мешающих невидимых рамок, поэтому цвет и стиль легко менять инструментом «Заливка» в редакторе TurboWarp.
